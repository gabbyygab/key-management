## 1. Project Overview

### What the system does

A campus key management system. Keys belong to rooms in buildings. Borrowers (faculty, staff, students) borrow keys. A guard on duty releases the key and confirms its return. Lost or damaged keys are reported as incidents. Everything important is logged, and users get notified.

### Entities (from the ERD)

| Table | Purpose | App |
|---|---|---|
| DEPARTMENT | Academic/admin departments (CICT, COE) | accounts |
| USER | System users with roles and approval status | accounts |
| BORROWER | People allowed to borrow keys | accounts |
| BUILDING | Buildings (ADM, CICT) | facilities |
| ROOM | Rooms inside buildings | facilities |
| KEY_CATEGORY | Master, Room, Cabinet, Gate... | keys |
| KEY | A physical key (original or duplicate) | keys |
| KEY_ASSIGNMENT | Long-term or temporary key holding | keys |
| GUARD_SHIFT | A guard's duty shift at a post | transactions |
| BORROW_TRANSACTION | One borrow/return event | transactions |
| INCIDENT_REPORT | Lost or damaged key reports | transactions |
| NOTIFICATION | In-app and email notifications | notifications |
| ACTIVITY_LOG | Audit trail of actions | audit |

### Roles

| Role | Can do |
|---|---|
| ADMIN | Everything, including approving users and changing roles |
| FACILITIES | Manage buildings, rooms, keys, categories, assignments |
| CUSTODIAN | Manage keys and assignments, resolve incidents, view reports |
| GUARD | Release and receive keys during a shift, report incidents |
| FACULTY_STAFF | View own borrowed keys and history, receive notifications |

> These permissions are a suggested starting point. Adjust them to match your school's actual policy before building the permission layer.

## 3. Phase 1: Accounts App

Holds `Department`, `User`, `Borrower`.

### `accounts/models.py`

```python
from django.conf import settings
from django.contrib.auth.models import AbstractUser
from django.db import models


class Department(models.Model):
    code = models.CharField(max_length=20, unique=True)
    name = models.CharField(max_length=150)
    is_active = models.BooleanField(default=True)

    class Meta:
        ordering = ["code"]

    def __str__(self):
        return self.code


class User(AbstractUser):
    class Role(models.TextChoices):
        ADMIN = "ADMIN", "Admin"
        FACILITIES = "FACILITIES", "Facilities"
        CUSTODIAN = "CUSTODIAN", "Custodian"
        GUARD = "GUARD", "Guard"
        FACULTY_STAFF = "FACULTY_STAFF", "Faculty / Staff"

    class Approval(models.TextChoices):
        PENDING = "PENDING", "Pending"
        APPROVED = "APPROVED", "Approved"
        REJECTED = "REJECTED", "Rejected"

    email = models.EmailField(unique=True)
    employee_id = models.CharField(max_length=50, unique=True, null=True, blank=True)
    contact_number = models.CharField(max_length=30, blank=True)
    role = models.CharField(max_length=20, choices=Role.choices, default=Role.FACULTY_STAFF)
    department = models.ForeignKey(Department, null=True, blank=True,
                                   on_delete=models.SET_NULL, related_name="staff")
    profile_picture = models.ImageField(upload_to="profiles/", blank=True)
    approval_status = models.CharField(max_length=10, choices=Approval.choices,
                                       default=Approval.PENDING)
    approved_by = models.ForeignKey("self", null=True, blank=True,
                                    on_delete=models.SET_NULL, related_name="approvals")
    approved_at = models.DateTimeField(null=True, blank=True)

    # Convenience helpers used across the project
    @property
    def is_approved(self):
        return self.approval_status == self.Approval.APPROVED

    @property
    def full_name(self):
        return self.get_full_name() or self.username

    def has_role(self, *roles):
        return self.role in roles

    def __str__(self):
        return f"{self.full_name} ({self.role})"


class Borrower(models.Model):
    class BorrowerType(models.TextChoices):
        FACULTY = "FACULTY", "Faculty"
        STAFF = "STAFF", "Staff"
        STUDENT = "STUDENT", "Student"
        OTHER = "OTHER", "Other"

    user = models.OneToOneField(settings.AUTH_USER_MODEL, null=True, blank=True,
                                on_delete=models.SET_NULL, related_name="borrower_profile")
    id_number = models.CharField(max_length=50, unique=True)
    first_name = models.CharField(max_length=100)
    last_name = models.CharField(max_length=100)
    borrower_type = models.CharField(max_length=10, choices=BorrowerType.choices)
    department = models.ForeignKey(Department, null=True, blank=True,
                                   on_delete=models.SET_NULL, related_name="borrowers")
    contact_number = models.CharField(max_length=30, blank=True)
    email = models.EmailField(blank=True)
    is_authorized = models.BooleanField(default=False)     # borrowing privilege
    authorized_until = models.DateField(null=True, blank=True)
    is_active = models.BooleanField(default=True)
    created_at = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ["last_name", "first_name"]

    @property
    def can_borrow(self):
        """True if active, authorized, and the authorization has not expired."""
        from django.utils import timezone
        if not (self.is_active and self.is_authorized):
            return False
        if self.authorized_until and self.authorized_until < timezone.localdate():
            return False
        return True

    def __str__(self):
        return f"{self.last_name}, {self.first_name} ({self.id_number})"
```

```python
from django.db import models


class Building(models.Model):
    code = models.CharField(max_length=20, unique=True)
    name = models.CharField(max_length=150)
    description = models.TextField(blank=True)
    is_active = models.BooleanField(default=True)

    class Meta:
        ordering = ["code"]

    def __str__(self):
        return self.code


class Room(models.Model):
    class RoomType(models.TextChoices):
        CLASSROOM = "CLASSROOM", "Classroom"
        LABORATORY = "LABORATORY", "Laboratory"
        OFFICE = "OFFICE", "Office"
        FACILITY = "FACILITY", "Facility"
        OTHER = "OTHER", "Other"

    class Status(models.TextChoices):
        AVAILABLE = "AVAILABLE", "Available"
        OCCUPIED = "OCCUPIED", "Occupied"
        MAINTENANCE = "MAINTENANCE", "Maintenance"
        INACTIVE = "INACTIVE", "Inactive"

    building = models.ForeignKey(Building, on_delete=models.PROTECT, related_name="rooms")
    room_code = models.CharField(max_length=30)
    name = models.CharField(max_length=150, blank=True)
    room_type = models.CharField(max_length=15, choices=RoomType.choices,
                                 default=RoomType.CLASSROOM)
    floor = models.IntegerField(null=True, blank=True)
    capacity = models.IntegerField(null=True, blank=True)
    status = models.CharField(max_length=15, choices=Status.choices, default=Status.AVAILABLE)
    is_active = models.BooleanField(default=True)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        ordering = ["building__code", "room_code"]
        constraints = [
            models.UniqueConstraint(fields=["building", "room_code"],
                                    name="unique_room_per_building"),
        ]

    def __str__(self):
        return f"{self.building.code}-{self.room_code}"
```

## 5. Phase 3: Keys App

### `keys/models.py`

```python
from django.conf import settings
from django.db import models


class KeyCategory(models.Model):
    name = models.CharField(max_length=100, unique=True)   # Master, Room, Cabinet, Gate...
    description = models.TextField(blank=True)

    class Meta:
        verbose_name_plural = "key categories"
        ordering = ["name"]

    def __str__(self):
        return self.name


class Key(models.Model):
    class Status(models.TextChoices):
        AVAILABLE = "AVAILABLE", "Available"
        BORROWED = "BORROWED", "Borrowed"
        OVERDUE = "OVERDUE", "Overdue"
        LOST = "LOST", "Lost"
        DAMAGED = "DAMAGED", "Damaged"
        INACTIVE = "INACTIVE", "Inactive"

    key_code = models.CharField(max_length=50, unique=True)       # unique key ID number
    room = models.ForeignKey("facilities.Room", on_delete=models.PROTECT, related_name="keys")
    category = models.ForeignKey(KeyCategory, on_delete=models.PROTECT, related_name="keys")
    description = models.CharField(max_length=255, blank=True)
    copy_number = models.PositiveSmallIntegerField(default=1)    # 1 = original, 2+ = duplicate
    status = models.CharField(max_length=10, choices=Status.choices, default=Status.AVAILABLE)
    remarks = models.TextField(blank=True)
    created_by = models.ForeignKey(settings.AUTH_USER_MODEL, null=True, on_delete=models.SET_NULL,
                                   related_name="keys_created")
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        ordering = ["key_code"]
        constraints = [
            models.UniqueConstraint(fields=["room", "category", "copy_number"],
                                    name="unique_key_copy_per_room_category"),
        ]

    @property
    def is_original(self):
        return self.copy_number == 1

    @property
    def is_available(self):
        return self.status == self.Status.AVAILABLE

    def __str__(self):
        return f"{self.key_code} ({self.room})"


class KeyAssignment(models.Model):
    class AssignmentType(models.TextChoices):
        TEMPORARY = "TEMPORARY", "Temporary"
        PERMANENT = "PERMANENT", "Permanent"

    key = models.ForeignKey(Key, on_delete=models.PROTECT, related_name="assignments")
    borrower = models.ForeignKey("accounts.Borrower", on_delete=models.PROTECT,
                                 related_name="assignments")
    assigned_by = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.PROTECT,
                                    related_name="assignments_made")
    assignment_type = models.CharField(max_length=10, choices=AssignmentType.choices,
                                       default=AssignmentType.TEMPORARY)
    start_at = models.DateTimeField()
    end_at = models.DateTimeField(null=True, blank=True)
    reason = models.TextField(blank=True)
    is_active = models.BooleanField(default=True)

    class Meta:
        ordering = ["-start_at"]

    def __str__(self):
        return f"{self.key.key_code} -> {self.borrower} ({self.assignment_type})"
```

> Note: `KeyAssignment` is a long-term hold (e.g. a professor permanently holds the office key). `BorrowTransaction` is a short-term borrow/return event. Keep them separate.

## 6. Phase 4: Transactions App

### `transactions/models.py`

```python
from django.conf import settings
from django.db import models


class GuardShift(models.Model):
    guard = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.PROTECT,
                              related_name="shifts", limit_choices_to={"role": "GUARD"})
    post = models.CharField(max_length=100)                  # e.g. Main Gate, Admin Bldg Desk
    shift_start = models.DateTimeField()
    shift_end = models.DateTimeField(null=True, blank=True)  # null while on duty
    is_on_duty = models.BooleanField(default=True)
    remarks = models.TextField(blank=True)

    class Meta:
        ordering = ["-shift_start"]

    def __str__(self):
        return f"{self.guard.full_name} @ {self.post} ({self.shift_start:%Y-%m-%d %H:%M})"


class BorrowTransaction(models.Model):
    class Status(models.TextChoices):
        ACTIVE = "ACTIVE", "Active"
        RETURNED = "RETURNED", "Returned"
        OVERDUE = "OVERDUE", "Overdue"
        LOST = "LOST", "Lost"
        DAMAGED = "DAMAGED", "Damaged"

    transaction_no = models.CharField(max_length=30, unique=True)   # TXN-20261011-0001
    key = models.ForeignKey("keys.Key", on_delete=models.PROTECT, related_name="transactions")
    borrower = models.ForeignKey("accounts.Borrower", on_delete=models.PROTECT,
                                 related_name="transactions")
    room = models.ForeignKey("facilities.Room", on_delete=models.PROTECT,
                             related_name="transactions")      # snapshot of key's room
    purpose = models.CharField(max_length=255)
    borrowed_at = models.DateTimeField(auto_now_add=True)
    expected_return_at = models.DateTimeField(null=True, blank=True)
    released_by = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.PROTECT,
                                    related_name="keys_released")
    guard_shift = models.ForeignKey(GuardShift, null=True, on_delete=models.SET_NULL,
                                    related_name="transactions")
    returned_at = models.DateTimeField(null=True, blank=True)
    received_by = models.ForeignKey(settings.AUTH_USER_MODEL, null=True, blank=True,
                                    on_delete=models.PROTECT, related_name="keys_received")
    return_confirmed = models.BooleanField(default=False)
    status = models.CharField(max_length=10, choices=Status.choices, default=Status.ACTIVE)
    remarks = models.TextField(blank=True)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        ordering = ["-borrowed_at"]

    def __str__(self):
        return self.transaction_no


class IncidentReport(models.Model):
    class IncidentType(models.TextChoices):
        LOST = "LOST", "Lost"
        DAMAGED = "DAMAGED", "Damaged"

    class Resolution(models.TextChoices):
        OPEN = "OPEN", "Open"
        INVESTIGATING = "INVESTIGATING", "Investigating"
        RESOLVED = "RESOLVED", "Resolved"

    key = models.ForeignKey("keys.Key", on_delete=models.PROTECT, related_name="incidents")
    transaction = models.ForeignKey(BorrowTransaction, null=True, blank=True,
```

## 10. Phase 8: Role-Based Permissions

```python
# accounts/decorators.py
from functools import wraps
from django.contrib.auth.decorators import login_required
from django.core.exceptions import PermissionDenied


def role_required(*roles):
    def decorator(view):
        @wraps(view)
        @login_required
        def wrapper(request, *args, **kwargs):
            if request.user.role not in roles and not request.user.is_superuser:
                raise PermissionDenied
            return view(request, *args, **kwargs)
        return wrapper
    return decorator
```

## 11. Phase 9: Business Logic (Services)

Put rules in `transactions/services.py` instead of views. This keeps views thin and the rules testable.

### Rules

**Borrowing a key**
- The guard must have an active shift.
- The borrower must pass `can_borrow`.
- The key must be `AVAILABLE`.
- Create the transaction, set the key to `BORROWED`, snapshot `room` from the key.
- Log it and notify the borrower.

**Returning a key**
- Only an `ACTIVE` or `OVERDUE` transaction can be returned.
- The receiving guard must have an active shift.
- Set `returned_at`, `received_by`, `return_confirmed=True`, status `RETURNED`.
- Set the key back to `AVAILABLE`.
- Log it and notify the borrower.

**Reporting lost/damaged**
- Create an `IncidentReport`.
- Set the key status to `LOST` or `DAMAGED`, and the transaction status to match (if linked).
- Notify admins and custodians.

### `transactions/services.py`

```python
from django.db import transaction as db_transaction
from django.utils import timezone

from audit.models import ActivityLog
from audit.services import log_activity
from keys.models import Key
from notifications.models import Notification
from notifications.services import notify
from .models import BorrowTransaction, GuardShift, IncidentReport


class BorrowError(Exception):
    """Raised when a business rule blocks a borrow or return."""


def generate_transaction_no():
    today = timezone.localdate()
    prefix = f"TXN-{today:%Y%m%d}-"
    last = (BorrowTransaction.objects.filter(transaction_no__startswith=prefix)
            .order_by("-transaction_no").first())
    seq = int(last.transaction_no.split("-")[-1]) + 1 if last else 1
    return f"{prefix}{seq:04d}"


def get_active_shift(guard):
    return GuardShift.objects.filter(guard=guard, is_on_duty=True).first()


@db_transaction.atomic
def borrow_key(*, key_id, borrower, guard, purpose, expected_return_at=None, request=None):
    shift = get_active_shift(guard)
    if not shift:
        raise BorrowError("You must start a shift before releasing keys.")
    if not borrower.can_borrow:
        raise BorrowError("This borrower is not authorized to borrow keys.")

    key = Key.objects.select_for_update().get(pk=key_id)   # lock row, prevents double-borrow
    if not key.is_available:
        raise BorrowError(f"Key {key.key_code} is not available (status: {key.status}).")

    txn = BorrowTransaction.objects.create(
        transaction_no=generate_transaction_no(),
        key=key, borrower=borrower, room=key.room, purpose=purpose,
        expected_return_at=expected_return_at,
        released_by=guard, guard_shift=shift,
    )
    key.status = Key.Status.BORROWED
    key.save(update_fields=["status", "updated_at"])

    log_activity(guard, ActivityLog.Action.BORROW, txn,
                 f"{borrower} borrowed {key.key_code}", request=request)
    if borrower.user:
        notify(borrower.user, Notification.Type.BORROWED, "Key borrowed",
               f"You borrowed key {key.key_code} ({key.room}). Ref: {txn.transaction_no}.",
               transaction=txn, key=key)
    return txn


@db_transaction.atomic
def return_key(*, transaction_id, guard, remarks="", request=None):
    shift = get_active_shift(guard)
    if not shift:
        raise BorrowError("You must have an active shift to receive keys.")

    txn = BorrowTransaction.objects.select_for_update().get(pk=transaction_id)
    if txn.status not in (BorrowTransaction.Status.ACTIVE, BorrowTransaction.Status.OVERDUE):
        raise BorrowError("This transaction is already closed.")

    txn.returned_at = timezone.now()
    txn.received_by = guard
    txn.return_confirmed = True
    txn.status = BorrowTransaction.Status.RETURNED
    txn.remarks = remarks or txn.remarks
    txn.save()

    txn.key.status = txn.key.Status.AVAILABLE
    txn.key.save(update_fields=["status", "updated_at"])

    log_activity(guard, ActivityLog.Action.RETURN, txn,
                 f"{txn.borrower} returned {txn.key.key_code}", request=request)
    if txn.borrower.user:
        notify(txn.borrower.user, Notification.Type.RETURNED, "Key returned",
               f"Key {txn.key.key_code} was returned. Thank you.",
               transaction=txn, key=txn.key)
    return txn


@db_transaction.atomic
def report_incident(*, key, incident_type, description, incident_date, reporter,
                    transaction=None, request=None):
    report = IncidentReport.objects.create(
        key=key, transaction=transaction, incident_type=incident_type,
        description=description, incident_date=incident_date, reported_by=reporter,
    )
    key.status = Key.Status.LOST if incident_type == "LOST" else Key.Status.DAMAGED
    key.save(update_fields=["status", "updated_at"])
    if transaction:
        transaction.status = (BorrowTransaction.Status.LOST if incident_type == "LOST"
                              else BorrowTransaction.Status.DAMAGED)
        transaction.save(update_fields=["status", "updated_at"])

    from accounts.models import User
    for staff in User.objects.filter(role__in=["ADMIN", "CUSTODIAN"], is_active=True):
        notify(staff, Notification.Type.INCIDENT, f"Key {incident_type.lower()}",
               f"Key {key.key_code} reported {incident_type.lower()} by {reporter.full_name}.",
               transaction=transaction, key=key)
    log_activity(reporter, ActivityLog.Action.STATUS_CHANGE, report,
                 f"Incident: {incident_type} {key.key_code}", request=request)
    return report
```

### Why `select_for_update`

Two guards releasing the same key at the same moment could both see it as `AVAILABLE`. The row lock inside an atomic block makes the second request wait and then fail correctly. (SQLite ignores row locks, but PostgreSQL/MySQL honor them. See Phase 15.)

## 13. Phase 11: Overdue Detection and Notifications

Nothing in Django runs on a schedule by itself. Use a **management command** run by a scheduler.

### `transactions/management/commands/check_overdue.py`

Create the folders `management/` and `management/commands/` (each with an empty `__init__.py`).

```python
from datetime import timedelta
from django.core.management.base import BaseCommand
from django.utils import timezone

from audit.models import ActivityLog
from audit.services import log_activity
from keys.models import Key
from notifications.models import Notification
from notifications.services import notify
from transactions.models import BorrowTransaction


class Command(BaseCommand):
    help = "Marks overdue transactions and sends due-soon / overdue notifications."

    def handle(self, *args, **options):
        now = timezone.now()
        soon = now + timedelta(hours=1)

        # 1. Due soon (within 1 hour), not yet notified
        due_soon = BorrowTransaction.objects.filter(
            status=BorrowTransaction.Status.ACTIVE,
            expected_return_at__gt=now, expected_return_at__lte=soon,
        ).select_related("borrower__user", "key")
        for t in due_soon:
            already = t.notifications.filter(notif_type=Notification.Type.DUE_SOON).exists()
            if t.borrower.user and not already:
                notify(t.borrower.user, Notification.Type.DUE_SOON, "Key due soon",
                       f"Key {t.key.key_code} is due at {t.expected_return_at:%H:%M}.",
                       transaction=t, key=t.key)

        # 2. Overdue
        overdue = BorrowTransaction.objects.filter(
            status=BorrowTransaction.Status.ACTIVE, expected_return_at__lt=now,
        ).select_related("borrower__user", "key")
        count = 0
        for t in overdue:
            t.status = BorrowTransaction.Status.OVERDUE
            t.save(update_fields=["status", "updated_at"])
            t.key.status = Key.Status.OVERDUE
            t.key.save(update_fields=["status", "updated_at"])
            if t.borrower.user:
                notify(t.borrower.user, Notification.Type.OVERDUE, "Key overdue",
                       f"Key {t.key.key_code} is overdue. Please return it now.",
                       transaction=t, key=t.key)
            log_activity(None, ActivityLog.Action.STATUS_CHANGE, t,
                         "Marked overdue by system", model_name="BorrowTransaction")
            count += 1
        self.stdout.write(self.style.SUCCESS(f"{count} transaction(s) marked overdue."))
```

Run manually:

```powershell

```

## 15. Phase 13: Testing

Write tests as you go, not at the end. Run them with:

```powershell
python manage.py test
```

### What to test (priority order)

1. **Services**: borrow, return, double-borrow, no shift, unauthorized borrower, lost/damaged flow.

3. **Registration/approval**: pending user cannot log in, approved user can.
4. **Model rules**: `Borrower.can_borrow` with expired authorization, unique constraints.

### Example

```python
from django.test import TestCase
from django.utils import timezone
from accounts.models import User, Borrower
from facilities.models import Building, Room
from keys.models import Key, KeyCategory
from transactions.models import GuardShift
from transactions.services import borrow_key, BorrowError


class BorrowTests(TestCase):
    def setUp(self):
        self.guard = User.objects.create_user("g1", "g@x.com", "pass12345",
                                              role="GUARD", approval_status="APPROVED")
        GuardShift.objects.create(guard=self.guard, post="Gate", shift_start=timezone.now())
        b = Building.objects.create(code="ADM", name="Admin")
        room = Room.objects.create(building=b, room_code="101")
        cat = KeyCategory.objects.create(name="Room")
        self.key = Key.objects.create(key_code="K-001", room=room, category=cat)
        self.borrower = Borrower.objects.create(id_number="E1", first_name="A", last_name="B",
                                                borrower_type="STAFF", is_authorized=True)

    def test_borrow_marks_key_borrowed(self):
        borrow_key(key_id=self.key.pk, borrower=self.borrower, guard=self.guard, purpose="Class")
        self.key.refresh_from_db()
        self.assertEqual(self.key.status, "BORROWED")

    def test_cannot_borrow_twice(self):
        borrow_key(key_id=self.key.pk, borrower=self.borrower, guard=self.guard, purpose="Class")
        with self.assertRaises(BorrowError):
            borrow_key(key_id=self.key.pk, borrower=self.borrower, guard=self.guard, purpose="Again")
```

## 16. Phase 14: Security Hardening

### During development

- Secrets only in `.env`, never in Git.
- Never trust the `role` field from a form. Only admins change roles.
- Use `{% csrf_token %}` in every POST form. Logout must be a POST.
- Use `get_object_or_404` and check object ownership (a FACULTY_STAFF user may only view their own transactions).
- Validate uploads: limit profile picture size and extensions.
- Add `AUTH_PASSWORD_VALIDATORS` (Django includes them by default; keep them).

### Before going live

Run Django's own checker:

```powershell
python manage.py check --deploy
```

Production settings:

```python
DEBUG = False
ALLOWED_HOSTS = ["keys.yourschool.edu"]

SECURE_SSL_REDIRECT = True
SESSION_COOKIE_SECURE = True
CSRF_COOKIE_SECURE = True
SECURE_HSTS_SECONDS = 31536000
SECURE_CONTENT_TYPE_NOSNIFF = True
X_FRAME_OPTIONS = "DENY"
SESSION_COOKIE_AGE = 60 * 60 * 8       # 8-hour sessions
```

Optional: rate limit logins with `django-axes` to block brute force attempts.

## 19. Common Problems

| Problem | Cause and fix |
|---|---|
| `Unknown command: 'tailwind'` | `django_tailwind_cli` missing from `INSTALLED_APPS` (use underscores), or package not installed in the active venv |
| `mkdir a b` fails in PowerShell | Use `mkdir a, b` or two separate commands |
| `Reverse accessor clashes` | Two FKs to the same model without distinct `related_name` values |
| `InconsistentMigrationHistory` after adding custom User | You migrated before setting `AUTH_USER_MODEL`. Delete `db.sqlite3` and all migration files except `__init__.py`, then redo `makemigrations` and `migrate` |
| `no such table` | Forgot `makemigrations` and `migrate` |
| Tailwind classes not applying | `tailwind runserver` not running, or `{% tailwind_css %}` missing in `base.html` |
| `ImportError: cannot import name 'User'` | Import `get_user_model()` or use `settings.AUTH_USER_MODEL` in FKs |
| Uploaded images not showing | Missing `static(settings.MEDIA_URL, ...)` in `urls.py` or `MEDIA_ROOT` not set |
| Pending users see "invalid credentials" | The custom backend blocks them before the form check. See note in Phase 7 |
| Double-borrow possible | Use `select_for_update` inside `transaction.atomic` and a database that supports it (not SQLite) |
| Circular import between apps | Use string references in FKs (`"keys.Key"`) and import inside functions when needed |
