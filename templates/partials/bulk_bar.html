{% include "partials/bulk_bar.html" %} bulk-actions.js shows it as soon as something is checked, writes the count and hides whichever action the selection cannot use: Archive for live rows (is_active=False, status=INACTIVE for keys), Restore for archived ones, and Delete forever only when every selected row is already archived. Delete forever is the one hard delete in the UI (accounts/retention.py). It cascades past the PROTECTed foreign keys — the row's keys, their borrow history, its schedule blocks — so it is deliberately unreachable from a live list: a row must be archived first, which gives Restore as the way back. {% endcomment %}
